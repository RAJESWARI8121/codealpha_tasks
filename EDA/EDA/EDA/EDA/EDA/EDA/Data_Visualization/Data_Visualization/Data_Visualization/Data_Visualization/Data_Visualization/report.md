# Data Visualization Report

## 1. Introduction
Data visualization represents information using charts.

## 2. Objective
To compare student marks using a bar chart.

## 3. Dataset

## 4. Tools Used
Python, Pandas, Matplotlib.

## 5. Methodology
1. Load the dataset.
2. Read student marks.
3. Create a bar chart.
4. Add labels and title.
5. Save the chart.

## 6. Result
A student marks comparison chart is generated.

## 7. Conclusion
Charts help us understand data easily.
