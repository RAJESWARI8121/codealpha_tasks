# Data Visualization Project

## Objective
To compare student marks using a bar chart.

## Tools Used
- Python
- Pandas
- Matplotlib

## Methodology
1. Load student data.
2. Read names and marks.
3. Create a bar chart.
4. Add title and labels.
5. Save the chart.

## Result
A bar chart showing student marks is generated.

## Conclusion
Data visualization makes data easier to understand.
