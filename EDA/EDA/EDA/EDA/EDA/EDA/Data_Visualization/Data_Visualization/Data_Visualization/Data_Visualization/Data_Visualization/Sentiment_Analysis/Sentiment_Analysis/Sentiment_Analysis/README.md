# Sentiment Analysis Project

## Objective
To classify customer reviews as Positive, Negative, or Neutral.

## Tools Used
- Python
- CSV module

## Methodology
1. Read customer reviews.
2. Check positive and negative words.
3. Classify each review.
4. Save results in a CSV file.

## Result
Reviews are classified into three categories.

## Conclusion
Sentiment Analysis helps understand customer opinions.
