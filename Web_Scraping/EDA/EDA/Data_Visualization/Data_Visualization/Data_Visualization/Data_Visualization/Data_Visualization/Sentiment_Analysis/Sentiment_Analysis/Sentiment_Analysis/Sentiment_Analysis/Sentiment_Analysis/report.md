# Sentiment Analysis Report

## 1. Introduction
Sentiment Analysis identifies opinions and emotions in text.

## 2. Objective
To classify customer reviews into Positive, Negative, and Neutral.

## 3. Dataset
The dataset contains customer reviews.

## 4. Tools Used
- Python
- CSV module

## 5. Methodology
1. Read customer reviews.
2. Convert text into lowercase.
3. Identify positive and negative words.
4. Classify each review.
5. Save results in a CSV file.

## 6. Result
Reviews are classified into three sentiment categories.

## 7. Conclusion
Sentiment Analysis helps understand customer feedback.
