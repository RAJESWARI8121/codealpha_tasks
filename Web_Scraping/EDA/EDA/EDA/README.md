# Exploratory Data Analysis (EDA)

## Introduction
EDA is used to understand and analyze a dataset.

## Objective
To analyze student marks using Python.

## Tools Used
- Python
- Pandas
- Matplotlib

## Steps
1. Load the student dataset.
2. Display the first five records.
3. Check dataset information.
4. Calculate statistical values.
5. Find missing values.
6. Visualize student marks.

## Result
The dataset is analyzed and a marks distribution chart is generated.

## Conclusion
EDA helps us understand data and identify useful patterns.
