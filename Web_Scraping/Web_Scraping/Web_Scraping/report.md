# Web Scraping Project Report

## 1. Introduction
Web scraping is a technique used to collect information from websites automatically.

## 2. Objective
To collect quotes and author names from a sample website using Python.

## 3. Tools Used
- Python
- Requests
- BeautifulSoup
- CSV

## 4. Methodology
1. Send a request to the website.
2. Read the HTML page.
3. Extract quotes and author names.
4. Store the extracted data in a CSV file.

## 5. Result
The program extracts quotes and author names and stores them in a CSV file.

## 6. Conclusion
This project demonstrates basic web scraping using Python.
