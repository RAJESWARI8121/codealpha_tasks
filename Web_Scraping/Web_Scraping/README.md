# Web Scraping Project

## Description
This project collects quotes and author names from a sample website using Python.

## Tools Used
- Python
- Requests
- BeautifulSoup
- CSV

## How to Run
1. Install required libraries:
   pip install -r requirements.txt

2. Run the program:
   python scraper.py

## Output
The scraped quotes and author names are saved in sample_quotes.csv.
